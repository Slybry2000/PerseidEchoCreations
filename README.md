# Perseid Echo Creations

Source for **[perseidechocreations.com](https://perseidechocreations.com/)**.

Perseid Echo Creations builds workflow automation and custom internal tools for
owner-led businesses. One workflow is assessed end to end, then built, tested,
documented and handed over. Founded and run by Bryan Piard. Based in Renton,
Washington; works with clients across the United States.

## What the business does

- **Workflow Opportunity Map** — one workflow, one recommended first build, one
  decision-ready plan. $750, credited toward a build signed within 30 days.
- **Build** — mapped, built, tested, documented, handed over with training and a
  post-launch bug-fix window. Most builds land between $3,500 and $9,000.
- **After launch, your choice** — take the keys and run it yourself (training
  included, no ongoing fee), keep it maintained month to month, or have it
  operated day to day.

Common starting points: quote follow-up, field paperwork to invoice, order
intake from email, appointment reminders, client intake and documents. Each is
written up as an honest buy-a-tool-or-build-it comparison under
[/workflows/](https://perseidechocreations.com/workflows/).

Sometimes the honest answer is not to automate something. That is a legitimate
outcome of the assessment and it gets said out loud.

## This repository

A static site — hand-written HTML and CSS, no framework — deployed by GitHub
Pages from `main` at the apex domain. `local/_build/build.js` generates the city
pages and `sitemap.xml`; add pages to `rootPages` there rather than hand-editing
the sitemap.
